Core Capabilities & Modules

Every layer of messiQ is built to provide an instant, reliable messaging experience.

Real-Time WebSocket & STOMP

Sub-millisecond two-way communication using Spring WebSocket and STOMP message broker. No polling, zero latency.

Live Online/Offline Presence

Automated session lifecycle listeners track user connectivity, broadcasting live status updates to all active contacts.

Instant Photo & Media Sharing

Multipart file upload service with safe unique file hashing, providing inline photo previews in conversation bubbles.

Chronological Message History

Persistent database queries retrieve conversations in chronological order with delivery receipts and read indicators.

Dual Light & Dark Theming

Figma-crafted Warm Ivory & Celadon for bright daytime and Obsidian & Forest Slate for distraction-free night focus.

Secure Authentication

SHA-256 hashed password protection, unique handle verification, and isolated tokenized session management.

ACADEMIC SPECIFICATIONS

Implemented Synopsis Algorithms

Strictly adheres to Chapter 4 of the Bachelor of Computer Application curriculum requirements.

Algorithm 1

User Registration

Validates username and email uniqueness, hashes passwords securely with SHA-256, and stores user entity into the database.

Algorithm 2

User Login & Session

Authenticates credentials, issues secure session token, and establishes WebSocket handshake for real-time presence.

Algorithm 3

Send Real-Time Message

Routes message payload through WebSocket destination /app/chat.sendMessage to pair topic and user queue.

Algorithm 4

Chronological History Retrieval

Queries database for pairwise messages where (sender=A ∧ receiver=B) ∨ (sender=B ∧ receiver=A) sorted by timestamp ascending.

Algorithm 5

Online / Offline Presence Broadcast

SessionConnectedEvent and SessionDisconnectEvent trigger automated presence broadcasts across /topic/status.
